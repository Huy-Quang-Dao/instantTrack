# InstantGMT project page

Static site for InstantGMT (branch `instantGMT-page`, served by GitHub Pages): `index.html`, `assets/css/site.css`, `assets/js/site.js`. Videos go in `media/`.

Placeholders (dashed boxes, "—" values) are filled in with the paper. Page design adapted from the SuperMimic project page (https://supermimic.github.io), with layout ideas from https://sailab.ai/nablamimic/.
