# InstantTrack project page

Static site for [InstantTrack](https://github.com/Huy-Quang-Dao/instantTrack) (branch `instanttrack-page`, served by GitHub Pages). `index.html`, `assets/site.css`, `assets/site.js`, videos in `media/`.

Videos show motions derived from LAFAN1 (Ubisoft La Forge, CC BY-NC-ND 4.0) and are for non-commercial research and illustration only. Page design adapted from the SuperMimic project page (https://supermimic.github.io).
